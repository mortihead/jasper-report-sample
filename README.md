# Руководство для контрибьютеров

## Обзор проекта

Проект `jasper-report-sample` — это Spring Boot приложение для генерации отчетов с использованием JasperReports. Приложение использует Maven в качестве системы сборки и Java 8 в качестве целевой версии.

## Структура проекта и организация модулей

```
src/
├── main/
│   ├── java/ru/mortihead/
│   │   ├── Main.java                 # Точка входа приложения
│   │   ├── config/                   # Конфигурационные классы
│   │   ├── model/                    # Сущности базы данных
│   │   ├── repository/               # Репозитории Spring Data JPA
│   │   ├── service/                  # Бизнес-логика
│   │   └── rest/                     # REST контроллеры
│   └── resources/
│       ├── application.properties    # Конфигурация приложения
│       ├── db/                       # Скрипты миграции Liquibase
│       └── report_templates/         # Шаблоны отчетов Jasper (.jrxml)
target/                              # Сгенерированные файлы сборки
pom.xml                              # Конфигурация Maven
```

## Команды сборки, тестирования и разработки

### Основные команды Maven

```bash
# Сборка проекта
mvn clean compile

# Сборка и запуск тестов
mvn clean test

# Создание исполняемого JAR
mvn clean package

# Запуск приложения
mvn spring-boot:run

# Установка в локальный репозиторий Maven
mvn clean install
```

### Запуск через IDE

Для запуска приложения через IDE используйте класс `ru.mortihead.Main`.

## Стиль кода и правила именования

### Соглашения по именованию
- **Классы и интерфейсы**: PascalCase (например, `CarEntity`, `ReportService`)
- **Методы и переменные**: camelCase (например, `getCarById`, `reportService`)
- **Константы**: UPPER_SNAKE_CASE (например, `MAX_RETRY_COUNT`)
- **Пакеты**: строчными буквами, разделенные точками (например, `ru.mortihead.service`)

### Организация кода
- Все классы моделей находятся в пакете `ru.mortihead.model`
- Репозитории Spring Data JPA находятся в пакете `ru.mortihead.repository`
- Сервисы с бизнес-логикой находятся в пакете `ru.mortihead.service`
- REST контроллеры находятся в пакете `ru.mortihead.rest`

### Форматирование кода
- Используйте отступы в 4 пробела
- Максимальная длина строки: 120 символов
- Всегда используйте фигурные скобки, даже для однострочных блоков

## Особенности проекта

### Генерация отчетов
- Шаблоны отчетов хранятся в `src/main/resources/report_templates/`
- Для работы с JasperReports используется `ReportServiceImpl`
- Поддерживается несколько источников данных для отчетов

### База данных
- Используется Hibernate в качестве ORM
- Миграции управляются через Liquibase
- Конфигурация базы данных в `hibernate.cfg.xml`

### Документация API
- Документация Swagger доступна по `/swagger-ui.html`
- Конфигурация Swagger в `SwaggerConfig.java`

## Разработка новых функций

При добавлении новых функций:
1. Создайте соответствующие классы в правильных пакетах
2. Добавьте необходимые зависимости в `pom.xml`
3. Напишите тесты для новой функциональности
4. Обновите документацию при необходимости
5. Проверьте совместимость с существующим кодом
